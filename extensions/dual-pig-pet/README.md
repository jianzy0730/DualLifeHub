# 双生猪猪 / DualPig Companion v0.2.0

面向 Operit 的角色身体扩展。页面中的小猪没有独立人设；触摸动画由前端立即执行，所有互动会写入本地队列，并在下一次正常模型回复前批量注入当前角色卡上下文。

## v0.2 的交互方式

```text
触摸小猪
  → 立即播放本地动画，不调用 LLM
  → 记录事件类型、顺序、持续时间与滑动距离
  → 下一次正常聊天时批量告知当前角色
```

因此连续点击、抚摸或揪尾巴不会产生连续模型请求，也不会阻塞动画。角色会在真正回复用户时知道此前发生了什么，但不必机械地逐条回应。

## 功能

- 分层 SVG 小猪，清晰缩放，不依赖位图。
- 点击头部或身体、长按、抚摸、拖动和揪卷尾巴。
- 十二种本地动作，触摸后立即进入动作队列。
- 互动事件按当前角色卡 ID 隔离并持久化。
- Prompt Finalize Hook 在下一次正常回复前注入最多 40 条待处理事件。
- 连续同类事件会压缩为“抚摸 ×N”，避免提示词膨胀。
- 亲密度、精力、情绪和最近互动保存在 ToolPkg 配置目录。
- 普通聊天中的角色仍可调用 `dual_pig_pet_core:pet_act` 主动控制小猪。

## 可执行动作

`blink`、`ear_twitch`、`tail_wag`、`head_tilt`、`bounce`、`lean_forward`、`nuzzle`、`shake`、`recoil`、`sit`、`sleep`、`tail_snap`。

## 事件上下文示例

```text
[双生猪猪身体互动记录]
在这次正常回复之前，用户已经通过可视化小猪身体与你发生了以下互动：
- 顺着你的头顶抚摸 ×3
- 捏住并揪了你的卷尾巴
这些动作都已经发生，不需要逐条机械回应……
```

## 构建

```bash
python scripts/build.py
```

输出：`release/DualPigCompanion_v0.2.0.toolpkg`

## 状态迁移

v0.2 会自动读取 v0.1 的 `pet_state.json`，补充 `pending_events` 与 `recent_events` 字段，不需要手动清除原有亲密度和精力。
